# Ledger 💰

A personal finance tracker built with Flask.

**Live demo:** https://Pandazzy3.pythonanywhere.com

## Features
- User accounts with hashed passwords
- Track income & expenses with categories
- Monthly budgets with progress bars
- Recurring transactions (rent, salary)
- Savings goals with deadlines
- Monthly reports with month-over-month comparison
- Email alerts when budgets are nearly exceeded
- Charts, dark mode, CSV export, filtering, search

## Stack
Flask · SQLAlchemy · Flask-Login · Flask-WTF · Chart.js · Bootstrap 5 · SQLite
