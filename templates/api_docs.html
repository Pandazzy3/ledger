🔌 Ledger REST API

Use these endpoints to integrate Ledger with your own scripts, mobile apps, or tools.

Authentication

Create a token on the API Tokens page, then include it in every request:

Authorization: Bearer <your-token>
Endpoints
MethodPathPurpose
GET/api/v1/meCurrent user info
GET/api/v1/expensesList expenses (supports start, end, category, kind)
POST/api/v1/expensesCreate an expense or income entry
GET/api/v1/expenses/<id>Get one entry
PUT/api/v1/expenses/<id>Update an entry
DELETE/api/v1/expenses/<id>Delete an entry
GET/api/v1/categoriesList categories
GET/api/v1/summaryTotals + charts data (supports start, end)
Example: list expenses from the last 7 days
curl -H "Authorization: Bearer YOUR_TOKEN" \
  "https://Pandazzy3.pythonanywhere.com/api/v1/expenses?start=$(date -d '7 days ago' +%Y-%m-%d)"
Example: create an expense
curl -X POST "https://Pandazzy3.pythonanywhere.com/api/v1/expenses" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"kind":"expense","amount":12.50,"category":"Food","description":"Lunch","date":"2026-09-23"}'
